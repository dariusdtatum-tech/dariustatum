# Legacy site — archived pages

These are the pages of the pre-voyage Evenfaring site — the multi-page layout
(`about.html`, `contact.html`, `communities.html`) that the studio site used
before the single-page "voyage" design replaced it. They were archived here on
2026-10-20, when the repo was reorganized around the voyage site.

They are preserved for their copy and content, as a record of the earlier site.
They are **not** linked from the live site, and their internal links and styles
reference the old layout (including the old root-level `style.css`), so treat
them as an archive, not a working site.

`privacy.html` was intentionally **kept live at the repo root** — it is not
part of this archive, so its URL stays stable.

The legacy site's binary assets stay in their root folders, documented as
legacy in the main README:

- Screenshots of the old pages: `previews/`
- Self-hosted fonts: `assets/fonts/`
- Font licenses: `assets/licenses/`

Everything here is also preserved in git history — the state of the repo
before this cleanup is commit `f48ab18`.
